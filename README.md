# SurfAlquila

Web de alquiler de material de surf (HTML y CSS). Datos ficticios.

## Páginas
index.html · catalogo.html · detalle.html · carrito.html · formulario.html · login.html

## Funciones representadas pero no implementadas
Acceso de usuarios, búsqueda, filtros, paginación, carrito (añadir/eliminar/recalcular) y envío del formulario.

## Flexbox y Grid
- Flexbox: cabecera y navegación, interior de las tarjetas, filas del carrito, grupos de acciones.
- Grid: catálogo y destacados (3 columnas, gap, filas que crecen, primera ficha ocupa 2 columnas).

Ilustraciones JPG y SVG sencillas creadas para el proyecto.
